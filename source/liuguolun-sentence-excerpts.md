# 《六國論》彈窗原句節錄記錄

每題彈窗只顯示包含目標詞語、且可獨立表達完整意思的官方原文句子；不再顯示整段文字。

| 題目詞語 | 節錄句 |
| --- | --- |
| 兵、利、弊 | 六國破滅，非兵不利，戰不善，弊在賂秦。 |
| 力虧、道 | 賂秦而力虧，破滅之道也。 |
| 喪、率 | 或曰：「六國互喪，率賂秦耶？」 |
| 蓋、強援、完 | 曰：「不賂者以賂者喪。蓋失強援，不能獨完，故曰『弊在賂秦』也。」 |
| 固 | 則秦之所大欲，諸侯之所大患，固不在戰矣。 |
| 思、厥、先、祖父、尺寸 | 思厥先祖父，暴霜露，斬荊棘，以有尺寸之地。 |
| 舉 | 子孫視之不甚惜，舉以予人，如棄草芥。 |
| 厭、彌、判 | 然則諸侯之地有限，暴秦之欲無厭，奉之彌繁，侵之愈急，故不戰而強弱勝負已判矣。 |
| 顛覆 | 至於顛覆，理固宜然。 |
| 與 | 與嬴而不助五國也。 |
| 斯 | 是故燕雖小國而後亡，斯用兵之效也。 |
| 始、速 | 至丹以荊卿為計，始速禍焉。 |
| 連、卻 | 後秦擊趙者再，李牧連卻之。 |
| 洎 | 洎牧以讒誅，邯鄲為郡，惜其用武而不終也。 |
| 革、滅、殆、盡、誠 | 且燕趙處秦革滅殆盡之際，可謂智力孤危，戰敗而亡，誠不得已。 |
| 向使、數、量 | 向使三國各愛其地，齊人勿附於秦，刺客不行，良將猶在，則勝負之數，存亡之理，當與秦相較，或未易量。 |
| 嚮 | 幷力西嚮，則吾恐秦人食之不得下嚥也。 |
| 劫 | 有如此之勢，而為秦人積威之所劫，日削月割，以趨於亡。 |
