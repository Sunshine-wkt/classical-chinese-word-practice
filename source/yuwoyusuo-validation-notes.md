# 《魚我所欲也》驗證記錄

## 本機閱讀頁

已以瀏覽器載入互動頁，確認頂欄顯示「首次答對 0 / 28」及「已完成 0 / 28」，並提供「重設進度」和「返回目錄」控制。教育局節錄原文分為兩段，段號依序為 1 與 2；可點選詞語以黃箋標示。

## 首題作答流程

開啟「舍」題目時，彈窗原句為「二者不可得兼，舍魚而取熊掌者也。」。選取錯誤選項後，頁面顯示「錯誤」及「本題嘗試：1 次」，四個選項仍可選取，未顯示正確答案。

補答選取正確答案後，「已完成」更新為 1 / 28，而「首次答對」維持 0 / 28；彈窗只顯示筆記正解「同『捨』，抛棄。」。另開啟「不為苟得」標記時，系統先呈現拆分詞「苟」的獨立題目及其完整句子節錄。

「苟」首次答對後，首次答對分數更新為 1 / 28；再次點擊同一原文標記時，彈窗改為顯示下一個拆分題「不為苟得」，確認兩個題目可依序完成。

已點擊《魚我所欲也》右上方「返回目錄」，成功回到統一索引頁。目錄上方頁籤及下方紙本索引卡均顯示第 06 篇《魚我所欲也》，排在《六國論》之後，並標示 28 個重點詞語。

## 視覺核對

已在桌面及手機寬度檢視練習頁和篇章目錄。新頁保留墨綠頂欄、暖紙閱讀卡、左側索引線、圓形段號及黃箋詞語標示；手機版的頂欄控制與原文閱讀區均維持清晰可用。目錄頁的新篇章以第 06 張紙本索引卡顯示，與既有篇章保持一致。

## GitHub Pages 公開版

GitHub Pages 部署成功後，公開版已顯示孟子《魚我所欲也》、28 題首次答對與完成進度，以及「返回目錄」連結。開啟「舍」題目時，彈窗原句為「二者不可得兼，舍魚而取熊掌者也。」，確認公開版只顯示含目標詞的完整句子節錄。

由公開版「返回目錄」連結可正確進入 `practice-hub.html`；頁面上方索引及第 06 張孟子《魚我所欲也》紙本索引卡均已顯示，卡片直接連至新練習頁並標示 28 個重點詞語。

## 苟字標示修訂

已將原文「不為苟得」的黃箋範圍縮為單一「苟」字，維持題目資料及頂欄總數為 28 題。手機版核對顯示「不為」及「得」均恢復為普通正文，只有「苟」保留黃箋標示。
