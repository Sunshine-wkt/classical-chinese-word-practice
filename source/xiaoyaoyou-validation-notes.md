# 《逍遙遊》驗證記錄

## 本機頁面與題目資料

已核對離線互動頁載入教育局指定的兩段節錄原文，頂欄顯示「首次答對 0 / 31」及「已完成 0 / 31」，原文中共 31 個校本筆記重點詞語可點選。

首題「貽」實機彈窗顯示完整原句「魏王貽我大瓠之種，我樹之成而實五石。」及四個辨義選項；筆記原有正解「贈送。」置於選項 C。

首題先選錯誤選項後，頁面只顯示「錯誤」並保留全部選項；其後補答「贈送。」即完成題目，但頂欄維持「首次答對 0 / 31」，只把「已完成」增為 1，符合補答不加分規則。

## 視覺與導航核對

桌面及手機版均已核對《逍遙遊》兩段原文、31 個黃箋詞語、頂欄進度與「返回目錄」連結。閱讀頁以段號、墨綠直脊及黃箋詞語建立紙卷式節奏；入口頁已將第 07 篇莊子《逍遙遊》置於《魚我所欲也》之後，並維持紙本篇章索引的顯示與直接開啟方式。

## GitHub Pages 公開版

公開學生版已核對：頂欄顯示「首次答對 0 / 31」及「已完成 0 / 31」，首題「貽」彈窗顯示完整句子節錄與四項選項，筆記正解「贈送。」置於選項 C。第 07 篇入口與「返回目錄」連結均已在公開版載入。
